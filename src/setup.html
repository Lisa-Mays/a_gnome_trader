Welcome

This wizard sets the bot up in a few minutes. You will create a Discord bot, invite it to your server, give it a name and status, and pick where alerts go. Nothing is saved until the last step.

You will need a Discord account and permission to add a bot to the server where alerts should go.

Choose an install folder

The bot keeps its settings, watch list, and logs next to its program file. Leave the field unchanged to run from where it is now, or type a different folder to copy everything there.

Create your bot and paste its token

  1. Open discord.com/developers/applications
  2. Click New Application, name it anything, click Create
  3. In the left menu click Bot
  4. Click Reset Token, confirm, then Copy

The token is like a password for your bot. It is saved only to config.json on this computer and sent only to Discord.

Invite the bot to your server

Open the link below, pick your server, and click Authorize. The link grants only what the bot needs:
